# Mientras te portes bien · Sitio web
Sitio estático (HTML + CSS + JS). Sin instalación ni build.

## Publicar en GitHub Pages
1. Creá un repositorio en GitHub y subí **todo el contenido** de esta carpeta (index.html en la raíz).
2. Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / carpeta `/ (root)` → Save.
3. En 1–2 minutos queda en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

## Qué completar (todo en `app.js`, arriba de todo)
- **Capítulos:** pegá el ID de YouTube en `youtube` y cambiá `estado` a `"disponible"` el día del estreno.
- **Equipo:** nombres, roles y fotos (archivos en `img/`).
- **Backstage y difusión:** copiá tus imágenes a `img/` con los nombres indicados (o cambiá los nombres).
- **Repositorio:** subí los archivos a `docs/` y completá `url`. Los vacíos muestran "Próximamente".
- **Tipografía de títulos:** poné `GhotiksCondensed-Book.woff2` (u `.otf`) en `fonts/`. Mientras tanto usa Barlow Condensed.
