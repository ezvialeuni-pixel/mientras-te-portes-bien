# Mientras te portes bien · Sitio web
Sitio estático (HTML + CSS). Sin instalación ni build.

## Publicar en GitHub Pages
1. Subí todo el contenido de esta carpeta a un repositorio público (index.html en la raíz).
2. Settings → Pages → Deploy from a branch → main / (root) → Save.
3. El sitio queda en https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/

## Qué completar en index.html
- Capítulo 1: pegá el link del video en el botón "Ver en YouTube". Ahora apunta al canal.
- Cada estreno: cambiá el chip "Próximo estreno" por "Disponible" y reemplazá el botón gris por un enlace (hay un comentario con el ejemplo).
- Backstage: poné fotos en assets/ y reemplazá los recuadros "pendiente".
- Equipo técnico y Equipo 4: completar nombres.
- Repositorio: subí archivos a docs/ y reemplazá los chips "Enlace pendiente" por enlaces.
